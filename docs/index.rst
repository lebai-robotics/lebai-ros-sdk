Lebai ROS Noetic SDK 文档
=========================

本项目提供 Lebai 机器人的 ROS Noetic 驱动。你可以连接真实控制器或仿真控制器，
订阅机器人状态，以及通过 ROS 服务和 action 控制机器人。本项目还提供 Python
示例和 LM3 的 MoveIt 1 配置。
